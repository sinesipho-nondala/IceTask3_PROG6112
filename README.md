Advanced arrays &amp; Advanced Inheritance
--------------
## What is this about?
the purpose for this Ice Task is to practice advanced arrays and advanced inheritance.
What I had to do was to create a Workshop class which is the abstract class that will store the variables that will be used in
the subclasses. Before I could create an Abstract class I first had to create an Interface. What this means is that there will be consistency, in other words it should have the same method names or it wont work.
